# 2026-10-11

## Local-run + package-publishing guide

Added `docs/LOCAL_SETUP_AND_PUBLISHING.md`: how to run SheetLens locally with the
engine package, how to use the package on its own (library + CLI), how to
publish `@shivam-dhyani/sheet-diff` to npm, and the order to do it in
(run locally with a live link → publish → switch the app to the published
version → deploy to Cloudflare Pages). Includes a pre-publish checklist, a
troubleshooting table, and an optional GitHub Actions publish workflow (not
created).

Verified while writing it (against the real repos):
- the library snippets (compare, report model, merge → patched `.xlsx`) run and
  give the documented numbers;
- `pnpm pack` produces a 15-file tarball that installs cleanly in an empty
  project — ESM import, CJS `require` and `npx sheet-diff` all work;
- `link:../sheet-diff` gives a real symlink and typecheck + production build pass
  against it, whereas the current `file:../sheet-diff` is a **snapshot copy**
  that goes stale after every engine rebuild (inode check);
- `@shivam-dhyani/sheet-diff` is unpublished on npm (404 on 2026-10-11).

Fix: `playwright.config.ts` hard-coded the cloud container's Chromium path, so
`pnpm e2e` would fail on any other machine. It now honours
`PLAYWRIGHT_CHROMIUM_PATH`, falls back to the container browser if present, and
otherwise uses Playwright's own install (`pnpm exec playwright install
chromium`). 6/6 e2e still pass.

Issues found in the engine and listed in the guide's pre-publish checklist (not
fixed here): stale README text (merge "soon"); CLI prints 92 for the
cell-by-cell contrast while the app/PRD say 89 (CLI sums all sheets, the report
model uses the primary sheet); `npm audit` shows 2 high advisories from the
pinned `xlsx@0.18.5`.
