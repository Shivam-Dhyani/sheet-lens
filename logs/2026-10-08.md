## Increment 5 — SheetLens web app shell + compare flow (M4, partial)

Scaffolded the browser-only app (Vite 6 + React 19 + React Router v7, Zustand,
vite-plugin-pwa) consuming the engine via `file:../sheet-diff`.

- `worker/engine.worker.ts` + `worker/client.ts` — the engine runs in a Web
  Worker (Comlink); the ArrayBuffer is transferred in; heavy data (IRs, result,
  report) stays in the worker (ADR-10); the UI pulls the compare summary and
  per-sheet marked windows (`getMarkedSheet`).
- `store/session.ts` — Zustand session (slots, phase, summary, ui).
- Landing (headline, mode tabs, two drop zones, "Try with sample files",
  offline/privacy badge) + `intake/DropZone` (File API, extension guard).
- Results: headline (FR-RES-01) + contrast line, summary cards (FR-RES-02),
  findings list + detail panel (FR-RES-03), sheet tabs, a diff grid with
  changed-rows/all filter, per-cell change/high/recalculated markers with old
  values, status pills, and mobile change cards (FR-RES-06). Copy-summary
  button (FR-REP-03).
- Privacy panel (FR-PRV-02) — Performance resource-timing network log.
- `public/samples/` — the compare + merge sample fixtures (FR-IN-09).
- `public/_headers` CSP already present; tokens.css design system (§12.9).

Tests: Vitest unit (format) + **Playwright e2e (US-01) in real Chromium** — the
samples compare in the worker and the UI shows "8 real changes found — 4 need
your attention", the four High findings, the 89-cell contrast, and the privacy
panel's "0 requests". Build is clean: main bundle 132 KB gzip (≤200 KB landing
budget), xlsx isolated in the 480 KB worker chunk.

Modules for this first pass (noted for a later refactor). Next app increments:
