# 2026-10-09

## Increment 6 — SheetLens reports (M5): Excel + HTML report renderers

Built the two downloadable report renderers that consume the engine's report
model (`buildReportModel`), both running inside the Web Worker and lazily
imported so they never weigh on first paint.

- `src/reports/excel-report.ts` — `renderExcelReport(model) → ArrayBuffer` via
  ExcelJS (lazy `import('exceljs')`). Three sheet kinds shaped to
  `reference_report_prototype.xlsx` (FR-REP-01):
  - **Overview** — title, privacy line, Old/New file, "Rows matched by", and an
    "At a glance" block whose counts are `COUNTIF` formulas over the All Changes
    table (so the figures are auditable and recalc live), each caching the
    engine's exact count as its result.
  - **All Changes** — severity-ordered table (`# Risk Where Invoice/Row Column
    What changed Old New What it means`) with an autofilter, frozen header, and
    risk-coloured Risk cells.
  - **"{Sheet} (marked)"** — Status column + data columns; changed cells
    highlighted (high / edited / recalculated) carrying their previous value as
    a cell note; removed rows placed by `afterKey` and struck through. Colour is
    never the only signal (Status labels + a labelled legend).
  - Indian `₹`/lakh number formats; a formula-injection note (xlsx string cells
    are inert — see `docs/IMPLEMENTATION_NOTES.md`).
- `src/reports/html-report.ts` — `renderHtmlReport(model) → string`: one
  self-contained HTML file, strict CSP meta, inline styles + a tiny inline
  search/risk-filter script, print styles (A4 landscape). No external requests
  (G-3 / FR-PRV); all text escaped.
- `src/reports/filename.ts` — `SheetLens_{new}_vs_{old}_{yyyy-mm-dd}.{ext}`
  (FR-REP-04). `src/reports/download.ts` — Blob download helper.
- Worker (`buildExcelReport`/`buildHtmlReport`) now renders from the stored
  report model and transfers the `ArrayBuffer` back; `ComparePage` gained
  "Download Excel report" / "Download HTML report" buttons alongside Copy
  summary.

Tests: Vitest unit (`report.test.ts`) round-trips the xlsx (sheet set, COUNTIF
formulas + cached results, changed-cell notes, struck removed rows) and asserts
the HTML is self-contained; Playwright e2e now downloads both reports and checks
the FR-REP-04 filenames in real Chromium. Fidelity: the report generated from
the Sales Register fixtures recalculates in LibreOffice headless to the engine's
exact counts (High 4 / Medium 9 / Info 3, rows +2/−1, 4 hand-edits, 1 formula
overwrite). Build clean — ExcelJS (940 KB) and the renderers sit in lazy chunks;
the landing bundle stays 132 KB gzip.
